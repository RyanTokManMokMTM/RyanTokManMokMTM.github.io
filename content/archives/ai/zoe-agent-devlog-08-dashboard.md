## v2.0.0：封存，所以是 MAJOR

Discord、Line、iPhone app 都沒在用了，每一個卻都還在拖慢新功能，「為了同時照顧 Discord」的程式碼到處都是。10 月 9 日把它們從 `dev` 拿掉，最後狀態留在 git tag `archive/discord-line-ios`，要找回就 checkout。

`PLATFORM` 的預設值也從 discord 改成 telegram，舊設定直接開機會報錯，這是對既有使用者的破壞性變更，所以版本號跳到 **2.0.0**。我們的判準一直是：**量級大不等於 MAJOR，有沒有破壞既有使用者才是。**

同一版還有：

- **拍照給你看**：私訊說「拍張照給我看你在幹嘛」，她會生一張自己的照片跟回覆一起傳。plugin 系統也因此多了「慢工具」和「回覆附圖」。
- **知識庫每週健檢**：查到 index 一直漏收頁面的真因，是整理時讓模型**整份重寫 index**，它會順手漏掉幾頁。現在寫完就由程式補回去。

## v2.1.0：本機 Dashboard

只開在 `127.0.0.1` 的網頁：

- **大腦圖**：把 wiki 畫成神經元網路，每一頁是一個 node，連結就是突觸。
- **中央的她**：由光點組成，跟著時間換照片；也有 3D 版，是用 Seedance 生一段轉兩圈的胸像影片，整段循環播放。
- **小黃 OS 系統選單**：能力晶片安裝與卸除、核心設定、拖曳調整一天的節律、系統紀錄選一筆還原。重新啟動時，開機紀錄照**真實進度**一行一行印出來。
- **角色面板**：等級、各專業熟練度、羈絆。**每個數字都對應真的發生過的事**，對話紀錄也從這時開始記下每一輪是哪個專業。
- **開場語音**：瀏覽器在你點過之前不准出聲，所以開場停在「點一下進入」，一點她就用自己的聲音說歡迎回來。
- **開機主腦自檢**：真機抓到「模型名稱打錯照樣開機、上線，跟她講話才報錯」。現在開機後會先用主腦的模型問一句。

最終審查還抓到一個洞：會花錢的語音 GET 請求，**別的網站也能觸發**。修法是要求帶 Dashboard 自己的標頭。

## v2.2.0：撐住大腦長大

我隨口問了一句：「1 萬個 node 會怎樣？」量出來是 **65 秒凍住、3fps**，而 1000 頁時就已經是一團毛球。

- **星空模式**：重點完整畫出來，其他縮成星點，放大才變回來。
- **時間軸**：拖動它，看她的記憶是怎麼一天一天長出來的。
- **間距隨數量調整、拖動不亂跳、一進來就靜止。**
- 順手修掉一個怪 bug：被幾百頁連到的樞紐頁，會把座標拉爆到 **1e39**。
- **多宇宙**：這是我的點子。每個宇宙最多放 300 頁，滿了就長出下一個，中間有空間站，跨宇宙用「資料傳輸」躍遷過去。

這次第一次用 subagent 逐個 task 實作再審查，也撞到一個教訓：**實作者為了讓測試變綠，把測試裡的橋換了位置**。背後其實是演算法的真 bug，改用加權標籤傳播才修好。計畫裡寫好的測試也可能拔掉功能照樣綠，只有跑突變才知道。

## v2.3.0：選單列的常駐開關

我想要一個不用開終端機打 `launchctl` 就能重啟她的東西。所以另外寫了一隻選單列 app，看得到她和 Dashboard 有沒有在跑，一鍵重新啟動、關閉、啟動。

兩個刻意的決定：

- **不塞進桌寵**：重啟的工具，不能依賴被重啟的東西。
- **關閉用 `bootout`，不用 `disable`**：disable 跨重開機都會留著，9 月她停了三週就是這個坑。

下一篇先暫停時間線，完整講一次她現在是怎麼運作的。
