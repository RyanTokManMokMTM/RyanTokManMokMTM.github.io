Zoe Agent｜開發簡介

發表於： 2026-10-31 分類於： 開發日記
字數： 857 閱讀：≈ 2分鐘 瀏覽： 評論：
總結摘要
小黃（Zoe）的開發簡介：背景、技術棧、GitHub 與截圖。

小黃（黃芷棋，Zoe）是一個跑在自己 Mac 上的個人 AI 夥伴：會聊天、記得你、懂投資但不報明牌，也能幫你打理一點生活。這篇只放重點：背景、技術棧、GitHub 和截圖。

Background

  • 2026-06-13 第一個 commit，一開始是學習用的 Discord 投資 bot。
  • 一週內長出人格「小黃」、長期記憶，以及會自己長大的知識庫。
  • 之後搬回 Mac 常駐，接上語音，長出三個殼：Mac 桌寵、Stack-chan 桌上機器人、本機 Dashboard。
  • 定位從「投資終端」轉成生活陪伴：Notion、Mac 控制、她自己的瀏覽器、自己學技能、自己排程、派寫程式的工作。
  • 2026-10-31 發布 v2.4.0：2,136 個 commit、約 3.6 萬行 Python、約 4,900 個測試、14 個正式版本。

完整的過程寫在開發日記系列，從〈小黃誕生〉到〈小黃長大了〉。

Tech Stack

類別技術
核心Python、SQLite、markdown wiki（LLM Wiki）
主腦Claude（Sonnet／Haiku）、Claude Agent SDK、Anthropic API、Codex CLI、Ollama
平台Telegram Bot API（long polling）
語音whisper.cpp（本機辨識）、PortAudio、ElevenLabs、OpenAI TTS
圖像gpt-image-1（參考圖鎖臉）、Seedance（3D 轉頭影片）
資料yfinance、Finnhub、Alpha Vantage、Binance、SEC
整合Notion API、macOS 提醒事項／行事曆、Spotify、Chrome
殼Swift（Mac 桌寵、選單列 app）、ESP32 M5Stack CoreS3＋PlatformIO（Stack-chan）
Dashboard原生 JavaScript＋d3
維運macOS launchd、git worktree、GitHub PR／Release
開發Claude Code、pytest（突變驗證）
